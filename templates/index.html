Multi-Layer Stacking for Machine Learning

A custom Python and Scikit-learn framework that combines multiple machine learning models across sequential layers to improve classification performance.

ABOUT

What is DeepStacking?

DeepStacking is a custom implementation of sequential stacking for machine learning classification. Instead of using a single machine learning model, DeepStacking organizes multiple models into different layers. The predictions generated by one layer are added as new features and passed to the next layer.

Multiple Models

Combine models such as Random Forest, Logistic Regression, SVC, Gradient Boosting and other Scikit-learn classifiers.

Sequential Layers

Each layer receives the original features together with predictions generated by previous layers.

OOF Predictions

Out-of-Fold predictions are generated using Stratified K-Fold validation to reduce training data leakage.
